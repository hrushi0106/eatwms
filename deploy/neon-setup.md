# Neon Database Setup

## Quick Setup (2 minutes)

1. Go to: https://neon.tech
2. Click "Sign up" → "Continue with GitHub"
3. Create project:
   - Name: `eatwms`
   - Region: `AWS us-east-1` (or closest to you)
4. Copy the connection string that appears
5. Save it - you'll paste it into Render

## Connection String Format
```
postgresql://username:password@ep-xxxx.aws.neon.tech/neondb?sslmode=require
```

## What this gives you:
- ✅ Free PostgreSQL database (512MB)
- ✅ Automatic backups
- ✅ No credit card required for free tier
- ✅ Perfect for production deployment
